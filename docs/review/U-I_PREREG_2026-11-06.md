## 1. W1 · T5 子因臂（vamorph v1.1，每臂 300s + ≥60s 间隔，洪水持续）

臂序：natfp（**跨 boot 复验**，C-283 E1-E2→E2 的第二窗）→ nat2q → nat8s → qoff。每臂并发
stock-scanary 对照（同窗 λ 基准）。

冻结判据（沿用 U-H RR = 事件(臂)/事件(对照)，带 [0.7,1.4]）：

| 臂 | 预注册解读 |
|---|---|
| natfp | RR ≥ 0.4 → 复验成立（U-H 值 0.856）；RR ≤ 0.1 → C-283 降级（boot 依赖性，记 E2→E1） |
| nat2q | RR ≥ 0.4 → 2 对 32B 事务已够（签名=少量 32B 事务存在）；RR ≤ 0.1 → 需满 4 对（计数敏感） |
| nat8s | RR ≥ 0.4 → **宽度不是充分判别**（同址同内容 16B 也可见→地址/序列模式判别）；RR ≤ 0.1 → **纯宽度判别成立**（隐身 shim 形态直接被验证） |
| qoff | RR ≥ 0.4 → 对齐不敏感；RR ≤ 0.1 → 32B 对齐参与签名 |

功效门：对照 λ ≥ 20 事件/300s/受害者（洪水档历史 118–449，预期超门 5–20×）。

## 2. W2 · T5 隐身落地（scanary_stealth vs stock scanary 同窗并跑）

600s 洪水窗，两受害者同机并发（各自独立日志/槽表），另加系统级此消彼长监控：
NE 台账（/data/gw/logs/ne_events.tsv + aee_exp mtime）窗前/窗后快照差。

冻结判据：
- **隐身成立**：stealth 受害者 inj=0 外写事件 = 0（同窗对照 λ ≥ 60 事件时 P(0) = e^-60）且
  stealth 进程存活无击杀；对照 λ 落自身 U-H 均值 ×[0.5, 2.0]（此消彼长窗口监控）。
- **隐身失败**：stealth 事件 ≥ 对照 × 0.4 → 单拷贝/内部残余即可触发 → 方案 A 需 musl 级改造。
- **此消彼长警报**（方案 A 生死判据之一）：窗内其他进程 NE 死亡数 > 前一同时长基线窗 × 3 且
  家族签名一致 → 记"再分配风险实证"，方案 A 降级。

**残余预算（构建审计，落档于结果文档）**：stock 每次 snprintf 热路径 32B 事务 ≈ 5
（4×prologue stp q @0x1014804 族 + 1×vsnprintf va_list 物化 @0x101b708）+ vfprintf core ≤3；
stealth = 0（shim）+ 1（vsnprintf 物化）+ core ≤3。即 stealth 臂隔离的是
**"4 对 stp-q FP 保存序列"** 这一结构，不是"零 32B 事务"。
