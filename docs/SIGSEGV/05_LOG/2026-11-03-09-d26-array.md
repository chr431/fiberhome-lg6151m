# 09 · D26 预注册 · 页池数组解剖与 owner 点名（2026-11-03 A1）

> **预注册文档：实验开窗之前写定并 commit。实验后只追加 §9 起的结果节，不改 §1–8。**
> 编号 09 顺延（01..08 已占用）。中性命名：不含目标网络名与个人凭证。
> 输入：D4（C-209）在 `0x84d40c64`（stride-0x10 `{status,pa}`）与
> `0x84d708d0`（stride-0x20 `{pa,0x1000,vmemmap,flags}`）发现受害页 PA
> `0xb08c6000`；第二受害页 `0xb0418000` 在保留带 `0x83e89578`。

## 1. 问题

D4 把写侧从「截断 VA 描述符」（H_trunc，已否证）转向「**正确的页 PA + 页池/环
登记**」。但 D4 只看了两个 8 KB 窗口、没有时间序列、没有 owner。本轮回答三个
问题：

1. 这两个数组**是什么**？（格式、条目数上限、status 语义、PA 分布、邻接结构、
   边界/头部字段）
2. 受害页 PA 在数组里的条目**是常驻还是新进**？崩溃**后**是否被消费/清除？
   （直接区分「陈旧登记」与「活跃使用」）
3. 数组的 **owner 是谁**？（内核里谁持有指向数组页的指针；能否符号化到驱动/引擎）

## 2. 假设（先写死）

- **H_stale**（陈旧登记）：数组是某 DMA 页池/环的登记表。受害页 PA 的条目在
  **该页被分配给 canary 栈之前**就已存在，并在崩溃后**继续常驻**（不被消费）。
  ⇒ 页被池回收复用为用户栈后，DMA 仍按池中 PA 写入。
- **H_live**（活跃使用）：受害页 PA 条目在**崩溃前 ≤1 个采样周期内新进**，或
  崩溃后**被消费/清除**（状态翻转/条目归零）。⇒ 页同时是活跃 DMA buffer 与
  用户栈（更严重的 double-use）。
- **H_coinc**（分配巧合）：数组只是**空闲页链表/分配器元数据**，受害页条目在
  页被交出（分配）时即被移除；即崩溃前最后一次采样里条目应已消失。
- **H_owner**：存在可点名的 owner（内核指针/符号/模块），能把数组归属到具体
  驱动或引擎。

## 3. 对象与测量

### 3.1 数组对象

| ID | 页 PA | D4 观测格式 |
|---|---|---|
| A1 | `0x84d40000` | stride 0x10，entry `{u32 status, u32 page_pa, u64 0}`，8 KB 内 490 个页地址 |
| A2 | `0x84d70000` | stride 0x20，entry `{u64 page_pa, u64 0x1000, u64 vmemmap, u64 flags}`，8 KB 内 137 个 |
| R1 | `0x83e80000` 带内 `0x83e89578` | 保留带 `0x82000000-0x8470ffff`，u32 页地址/长度交错流 |

### 3.2 全量解剖（静态，canary 前）

1. 每个数组 dump **64 KB**（16 页，覆盖数组真实边界与前后邻接），另加**前后
   各 2 KB**（与 64 KB 合并即前后各 2 KB 在窗口内）。
2. 解码：按 stride 切 entry；统计 status 值分布（全 32 位值）、PA 字段分布
   （落在 System RAM / reserved 带 / 非页对齐 / 0 / 重复）、非零 entry 计数、
   数组起止边界（首个/末个非零 entry 的偏移）。
3. 邻接结构：检查数组页前后是否出现 magic、计数、锁、指针字段（任何 8B 值
   落在 vmalloc/线性映射区且非页 PA 的候选）。
4. **与 D4 的 32 个记录页 PA 全量比对**（`scan_logs_raw.txt` 中
   `0x0109a8c000000641` 的非自身命中页），以及两个受害页 PA。

### 3.3 时间序列（canary 窗）

- canary：`vsurv5`（D4 同款，md5 设备侧核对），后台运行。
- 采样：**每 30 s** dump A1/A2 的 8 KB 窗口（与 D4 同格式，保证可比）+
  `/proc/uptime` + `h5_*` 文件清单。每份 dump 落到设备
  `/data/repro/d26/arr_<seq>_<ts>.txt`，窗后一次性拉回 PC。
- 崩溃：轮询 `h5_<pid>_<hit>.bin` 新增；每次崩溃立即（≤10 s）：
  ①解析 dump 头（x2/sp/fault）；②`patrace` 把 x2/sp 翻成 PA；③立即 dump
  A1/A2；④记录 canary pid 的启动时刻（栈页分配时刻）。
- 分析：
  - **进入时机**：受害页 PA 首次出现在数组采样序列的时刻 vs 崩溃时刻
    （用 canary 进程启动时刻作「页成为栈」的上界）。
  - **消费**：崩溃后 ≥2 个采样周期（60 s）内条目是否变化/归零/状态翻转。
  - 每个采样把 A1/A2 全部 entry 的 PA 集合与 canary 栈页 PA 集合求交。

### 3.4 Owner 点名（三重）

1. **指针扫描**（`rangescan`，新 oneoff）：全 DRAM 扫 8B 值落在
   `[A_page, A_page+0x2000)`（A1/A2 各一次）；另扫
   `vmemmap struct-page` 指针（`0xfffffffe00000000 + (pa>>12)*0x40`）与
   数组 PA 的 4B/8B 形式。self 标记同 pascan2 规则。
2. **邻域判读**：若找到持有者指针 → 取其所在页 dump 2 KB，按 8B 值分类
   （vmalloc/module 范围、函数指针候选、常见结构字段模式），再用同 boot
   kallsyms 快照符号化（离线）。
3. **静态签名交换**：把本轮 dump 的精确格式（status 值集合/字段宽度/条目数
   上限/stride/边界偏移）写入 §9 结果节，供 A2 的「stride-0x10 {status,pa}
   数组写入循环」指令签名离线比对。

## 4. 仪器

| 项 | 内容 |
|---|---|
| `rangescan` | 新 oneoff：`rangescan <start> <end> <lo> <hi> <4\|8>`；8B/4B 步进，打印 `HIT pa page off v pre post self`；self = 页内含工具名/参数字符串；计数不截断（打印上限 512） |
| `pascan2` | D4 既有件（md5 `de661bdd71394cfb533d4c2daa4e71d7`），用于精确值复扫 |
| `patrace.ko` | 只读 VA→PA（既有件；`echo "<pid> <hexva>" > /proc/patrace`） |
| `vsurv5` | canary（D4 同款；`/data/repro/h5_<pid>_<hit>.bin`） |
| dump | `dd if=/dev/mem bs=1 skip=<pa> count=<n>` + `hexdump -v -e '1/4 "%08x\n"'`（与 D4 arrays.txt 同格式） |
| 正对照 | ①数组内已知稳定 entry（D4 的 `0x84d40c64` 等）在 30 s 序列中可复现；②`marker` 4 值在窗内可被 pascan2 命中（证明扫描器活着） |
| 可读性 | 每次全 RAM 扫描统计 `pages_read/pages_unreadable`；≥90% 门禁 |

## 5. 窗与有效性门禁（任一不满足 ⇒ 对应判据 INVALID）

1. `boot_id` 窗内不变；无 kernel oops/panic；
2. 每个采样都有 `/proc/uptime` 与完整 8 KB dump（缺一记 gap，不插值）；
3. 至少 **2 次可用 canary 崩溃**（x2 落在用户栈区间、dump 头可解析）才判
   时间序列判据；否则只出静态解剖 + 判决降级为「不可判」；
4. 正对照：数组稳定 entry 在序列中可复现 + marker 4/4；
5. 每次崩溃后立即读 `TRY_A`（misc p1 offset 2060，期望 `0f 00 01 00 …`）；
6. 收窗：canary kill、0 个我方模块、`patrace` rmmod、`TRY_A` 低字节 = 0。

## 6. 判据（预写死，不改）

- **H_stale 成立**：对 ≥2 次崩溃，受害页 PA 在**该 canary 启动后的第一个采样**
  即已在数组中，且崩溃后 ≥2 个采样保持（值/状态不变）⇒ 陈旧登记。
- **H_live 成立**：受害页 PA 在崩溃前 ≤1 个采样周期才出现，**或**崩溃后 ≤60 s
  内条目被清除/状态翻转 ⇒ 活跃使用。
- **H_coinc 成立**：受害页 PA 在崩溃前最后一次采样已不在数组中（或数组条目
  在分配时被移除的明确证据）⇒ 数组只是分配器空闲链表。
- **H_owner 成立**：找到 ≥1 个非自身、非受害者栈页的持有者指针，且能归属到
  具体符号/模块/结构；否则记「owner 未点名」并给出残余盲区（不可读区、
  硬件内部）。
- 判读分层：数组内 PA 若为**非页对齐**或落在 reserved 带，单独计数，不与
  System RAM 页 entry 混算。

## 7. 停止规则

- **仪器/内核崩溃预算 ≤2**（canary 的 SIGSEGV 是观测对象，不计入）；
- 单条设备命令 ≤8 min；串口/SSH 异常连续 2 次即停；
- 窗口 ≤90 min；**设备侧动作 15:30 前收完，15:45 硬停出报告**；
- 同一仪器缺陷重复出现即停，不改判据救场。
