## 1. 关键新事实（W2 起点，均为 E2 级或待验）

- 映射：**AP PA = MED VA − 0x22500000**（0x38013000↔0x15b13000 值对账：+0x3c=0x600、
  +0x60=0xf8ffffff、+0x64=0x0fffffff、+0x70=1、+0x90=0x2c0000，与离线 cfg 逐项吻合）。
- MED dump 标签块（AP 视图，基线已拉）：FDMA_HNAT_INFO 0x15105900 = {环基 0x9fed08c0,
  0x70e4, 0x26c6, 0x26c7}；INFO 0x15105a00 = {0x40000101, 0x40002004, …, +0x14=0x26c6,
  +0x2c=0x08000040, +0x30=0x26c78100}；MDMA_TX 0x15105400/0x15105500；TXRX_INFO 0x15105600。
- /proc/medhw/dram = TX_DESC 环全量（6.4MB，基线已拉）；/proc/medhw/cr_dump = MED 寄存器面。

## 4. W3 判据（断供 ABAB，重启容忍；门禁未过则跳过并记录）

- 候选优先级：① INFO 0x15105a00 的使能位（bit0 假设——先备份原值、写 0 仅一位）；
  ② INT_MNG 0x15b130xx 的 hnat 通道掩码位；③ 其它 W2 新发现。
- 每 B 臂：只写 1 个寄存器、先读后写、写后回读、300s 窗测 **环生产速率**（两遍环快照
  记录数差）+ 同窗 λ（scanary_ctl 对照）；臂末回滚并复读。
- **判决**：B 臂环生产 ≤ 0.2×A 且 λ RR ≤ 0.5（95%CI 上界<1）⇒ T1 通道因果成立（判层 I）；
  环生产不变而 λ 变 ⇒ 内容非此环（C-258 修订）；环断而 λ 不变 ⇒ 内容另有源（重大）。
- **中止线**：2 次挂死（WDT）或启动门异常 ⇒ W3 终止。
- 代价三报：吞吐（洪水回执）、ping 延迟、UL-DL 状态（每 B 臂）。
