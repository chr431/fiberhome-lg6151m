# 仪器清单与读数边界（2026-10-27）

本目录是**一次性实验仪器**（不入 VERSIONS 注册表）。源码正本在 `tmpfiles/repro/`，
设备在 `/data/repro/`。每条都写清**用途**与**已知盲区**——盲区比用途重要。

| 仪器 | 用途 | 已知盲区（引用结论前必读） |
|---|---|---|
| `buddyscan*.ko` | 空闲页签名普查（唯一普查仪器） | `hits_now` 是 `maxhits` 饱和值；`maxhits` 截断**遍历**而非输出，每轮从最低址重来 ⇒ `distinct` 是低址前缀速率。**全量扫描只要 0.09 s**，用 `maxhits=0`（需先改语义）或 `>64`。只读页尾 64B |
| `dpscan*.ko` | dpmaif 寄存器/环窗/BAT 表只读采样 | 只读；判据必须严格对齐（先判 `(v&0x7ff)==0` 再取页，不许先掩后判）。**禁止经驱动 vmap 读 `ccci_tag_mem`——会 SEA 重启** |
| `dphook.ko` | dma_map 三站点 shim + 环生命周期 | **已退役**：文本补丁对运行中的 DMA 非原子；只认硬编码站点；实测从未观测到 RX 路径。变化判据用 xor 折叠，**对同值重写失明** |
| `dpreg.ko` | 寄存器窗盲 dump | **已退役**：insmod 一次性快照、每窗仅前 0x200、PA 上限 0xa0000000 |
| `dpclamp.ko` / `dpquar.ko` | 页隔离栈 | **已退役**（无实测收益 + 三次内核事故）。`whits` 三处失明 |
| `dpbatfix.ko` / `pinq.ko` | 清/钉住 BAT/PIT 基址所指页 | 判决**未裁决**（四轮 A/B 日志落 /tmp 已随重启丢失）。曾实测到 `+0x180` 指向已回 buddy 的页 |
| `cellguard.sh` | 蜂窝流量硬上限守护 | 2 s 轮询，单位 B；台账跨重启累加。**加载器一停必须立刻复原模式**（否则网关自身流量继续烧额度） |
| `manifest.sh` | 运行清单 + 负结果纪律 | 见文件头 |

## 十条读数纪律

详见 `lg6151m-public/docs/SIGSEGV_ANALYSIS.md` §7。摘要：

1. 任何「零」写成「0 / N 次观测，检出下限 X」；
2. 计数器先查上限，再谈「噪声 ≈ 0」；
3. 用摘要判变化 = 对同值重写失明，必须比内容；
4. `copy_from_kernel_nofault` 不防 SEA——判断依据是「这块映射是否已被证实可读」；
5. vmalloc 地址跨重启不稳定，运行时解析；
6. 只在页尾取样会制造偏差；
7. 每次运行落 manifest；
8. 用 uptime 重建时间排序键（`date` 与 `/proc/uptime` 是两个 fork）；
9. 热路径 O(1)，锁内不许 O(n)；
10. 设备侧命令串禁止出现 `$`。
