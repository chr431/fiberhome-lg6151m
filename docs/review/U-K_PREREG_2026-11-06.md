## 0. 本轮两条线

1. **线 2（先）**：T1 流量类别判定——同一负载下"本地 INPUT" vs "经转发路径" vs "空闲"，
   三臂 λ + 环生产速率双观测，判定 C-258 链①（内容馈源）存续形态。
2. **线 1（后）**：内核头树重建（**已完成，编译通过**）+ 设备验证 + **MED 停止调用**：
   `dpmaif_stop_rx_sw()`（无参厂商函数）→ 环生产/λ/MED DL 路径观测 → `dpmaif_start()` 恢复。

## 1. 线 2 判据（冻结）

**臂设计**（每臂 300s 设备单调钟，scanary_ctl 常驻对照；臂间 ≥60s）：
- A：本地 INPUT 洪水（PC→192.168.9.1:37777，3×800pps）——已知基线档
- B：转发路径洪水（PC→110.65.xx.127:37777 经静态路由强制走设备；同 pps）——须先证
  转发确实发生（conntrack 出现该五元组 或 WAN tx 计数增量）
- C：无洪水（地板档）

**测量**：λ（scanary inj=0 事件/300s）+ 环索引差（每臂前后 cr_dump 的 0x15b14020 族）+
WAN 计数（/proc/net/dev eth0 tx bytes）+ conntrack 抽样。

**判决（RR = 臂/同臂对照 λ）**：
- λ_B ≥ 2×λ_A → "转发路径特异性"成立 ⇒ 链①以"转发流内容"形态存续（C-258 部分维持）；
- λ_B ∈ [0.7,1.4]×λ_A → 流量类别无关 ⇒ λ 的流量响应非转发路径开关（CPU/系统活动假设胜）；
- λ_C ≤ 0.5×min(λ_A,λ_B) 否则"地板不成立"异常记录。
- 环生产速率对角：若环差(B) ≥ 2×环差(C) 而 λ_B≈λ_C → 环与 λ 解耦（强化 C-295）。
- 若 B 臂转发验证失败（conntrack 无记录）→ 该臂作废，只报 A/C。

## 2. 线 1 判据（冻结）

**前置**：
1. 头树重建**已过编译门**（emiuctl.c → out/emiuctl_test.ko，132984B；与原 ko Δ0.09%）。
2. 设备侧 kallsyms 可解析 `dpmaif_stop_rx_sw`（KALLSYMS_ALL 且 kptr_restrict 允许）；否则
   用"外部符号运行时地址 + vmlinux.elf 静态偏移差"换算。
3. `emiuctl_test.ko` insmod 成功且 `peek`/`call` 可用 = **头树重建的设备级验证**。

**实验（重启容忍）**：
- 基线：环生产两点（≥90s 间隔）确认活跃（~0.5 rec/s 档）。
- 臂 S1：`call <dpmaif_stop_rx_sw> 0` → 其后 3 点 cr_dump（每 ≥60s）+ 并发 scanary λ。
- 臂 S2（若 S1 无效应且环仍活跃）：`call <dpmaif_stop_hw> 0` → 同观测。
- 恢复：`call <dpmaif_start> 0` → 两点 cr_dump 确认恢复；MED DL 功能抽查（ccmni/netdev
  状态、LAN/WAN 连通）。
- **判决**：环生产速率 B 臂 ≤0.2×基线 ⇒ **MED 侧停止可断供**（T1 供给面首个可执行控制点，
  E2）；环不变而 MED DL 功能变化 ⇒ 环生产独立于 DPMAIF RX（链①再次收窄，供给面转向
  FE/MED 内部）；两头都不变 ⇒ 该 stop 与 hnat_info 无关（继续找 med IPI 停止协议）。
- **中止线**：2 次挂死（WDT）或恢复失败（dpmaif_start 不回环生产）→ 记录并转收尾。
