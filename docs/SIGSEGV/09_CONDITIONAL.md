# 09 · 命中的条件分布（R4，2026-11-01）

前置（见 [08_CORRELATION.md](08_CORRELATION.md)）：写入者锁定在**有线端口共用 EDMA RX 的「每 RX 包一次机会」路径**，
速率 1.3 ± 0.2 命中/千包；具体时序窗口未定位。

本文回答：**命中在时间、记录字段、流量形态上的条件分布是什么？**

## 方法

- 数据：设备 `/data/repro/h4_*.bin` 全量 **2554** 份（canary 转储，每份 120 B 头 + 8×4 KB 栈页）。
- 提取：`/data/repro/h4_meta.sh` → 每文件一行 `file ts pid hit x2 top fault_addr`（`fault_addr` = 记录 word0）。
- 拉取：分页 + **行数断言 2554 == 2554**（规避"大输出截断"坑）。主机副本 `_local/evidence/crash-root/h4_meta.txt`。

## 结果 1：**「命中成簇」不成立 —— 那是速率假象**（已自我撤回）

**初版错误做法**：把三段不同速率（静默 1.8/min、传输 127.6/min、回落 0.5/min）混在一起，
按 1 秒粒度统计"同秒 ≥2 个不同 canary"，得到 21.7%，据此宣称"成簇"。

**正确做法**：按段分开 + 速率匹配泊松零模型。干净的 T1–T2 LAN 段（λ = 631/300 = **2.10 命中/s**）：

| 量 | 观测 | 独立 4-canary 泊松零模型期望 | 判定 |
|---|---|---|---|
| 同秒 ≥2 个**不同 pid** 的秒数 | **131** | **127.0** | 比值 1.03，**无超额** |
| 同秒 ≥2 次命中的秒数 | 131 | 186.4（同速率泊松） | 观测**低于**泊松 |
| 同 canary 间隔 p50 / p90 | 1 s / 2 s | 1.32 s / 4.38 s（指数） | 尾部**更短**（比泊松更规则，不是突发） |

（静默段 n=9、回落段 n=3，样本太小，不做分布推断。）

**结论**：**速率匹配后与独立泊松过程无显著差异** → 没有证据支持"共享页/突发批次"模型。
教训：**在 1 秒粒度、2 次/秒的速率下，泊松过程本来就长得像"成簇"**；这是又一次「判据集合 ≠ 目标集合」。

## 结果 2：记录 word0 **既不是包长、也不是环槽位**

- 1723 / 2322 的 word0 < 1 MB；**1733 个不同取值**，范围 0–597004。
- 落在「包长区间 [0x500, 0x700]」的只有 **2 / 1723** → **不是包长**。
- 取值范围远超 512 项 RX 环的索引范围 → **不是槽位索引**。
- 高频重复值：`58511 (0xE48F) ×47`、`55439 (0xD88F) ×36`、`2103 (0x837) ×19`。
  - 但 58511 的 47 次分布在**两个独立会话**（分钟偏移 0/92.6/193.8 属旧会话，75566+ 属本轮），
    **不是某段时间卡住** → 不是"同一槽位被反复写"。
  - 58511 与 55439 相差 0xC00=3072 只是巧合：对全部 1733 个取值做 `%0xC00` / `%0x3000` / `%32` 检验，
    **均无集中**（`%32` 各余数 60–70 次，近乎均匀）。
- → 更像**数据相关的计数器 / 序列号 / 时间戳**，不是地址、不是索引、不是固定槽位。
- 附带确认：`top - x2` 在 **2322/2322** 恒等于 **912 (0x390)**（与既有 C-052 一致）。

## 结果 3/4：包长相关性与 CPU 相关性 —— 待流量形态实验（排队）

| 臂 | 工具 | 形态 |
|---|---|---|
| L 大包 | `_local/lan_rx_gen.py --rate-mb 2` | ≈1400 B/包、~1500 pps |
| S 小包 | `_local/lan_pkt_flood.py --pps 20000 --size 64` | 64 B/包、20 kpps |

- S 臂「命中/千包」显著高于 L 臂 → 小包更容易触发（每包固定概率）；
- 两臂相同 → 与"每包一次机会"一致，包长无关。
- 磁盘预算：S 臂 60 s × 20 kpps = 120 万包，按 1.3/千包 ≈ 1500 次命中 ≈ 48 MB；/data 余量 1.4 GB（已用 37%），足够。
