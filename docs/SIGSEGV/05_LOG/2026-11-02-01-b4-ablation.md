# 01 · B4 模块消融矩阵预注册（v4.1 正常态 · boot 期不加载 · 2026-11-02）

> **预注册文档：今晚设备会话之前写定。** 实验后只追加 §10–12，不改 §1–9。
> 承接 C-187（lab 内核集合级消融：写入者 ∈ {厂商内核内建, 厂商 .ko, CCCI 依赖之 MD}，集合不细分）。
> 本实验把该集合中**可加载模块子集**继续二分：mt_wifi 全族 / WED-WARP 对 / hw_nat。
> 执行单（分步命令/预期/失败分支）见本地 `_local/investigations/sigsegv-tools/phase-AB/B4-runbook.md`（非本仓文件）。
> 本文档中性信息：不含部署目标网络名与个人凭证。

## 1. 问题

32B 栈记录的写入者是否落在 v4.1 运行态实际加载的三个嫌疑模块集合之一 ——
**S1={mt_wifi 全族}**、**S2={mtk_wed（+经 mtk_wed 喂入的 warp 路径）}**、**S3={hw_nat}** ——
即：把某集合在 boot 期不加载后，同夜 scanary 自扫描观测的真命中（inj=0）是否消失？

## 2. 假设

- **H1（依赖其一）**：写入者的生产/搬运链需要 S1∪S2∪S3 中至少一个集合在位 ⇒ 任一对应消融臂真命中为 0（在检出下限内），而同夜夹逼基线臂（arm0）真命中 ≥1。
- **H0（三者皆不依赖）**：三个集合全部消融后写入仍发生 ⇒ 写入者 ∈ {内核内建, MD/CCCI, 其它 .ko, 与本三集合无关的机制}（C-187 集合的剩余部分）。
- **机制前提 H-M（本实验成立的前提，须先验证）**：
  a) v4.1 上厂商 .ko 的加载者**只有** procd rcS 链里的 `S10boot → /sbin/kmodloader → /etc/modules.d/*`（实证：v4.1 已删 S99zmtk_boot_done，其唯一尾行调用的 FH rcS/fhdrv_wifi_init_BE5000.sh 从不运行；s0-evidence snap.modules 164 项含 mt7992/mtk_wed/mtk_warp/hw_nat 且**零 fhdrv_\*** 模块）。
  b) **唯一可写的 pre-kmodloader 注入点 = /etc/preinit 第 2 行的 babysitter**（/data/rescue/babysit.sh，manifest 件）：pstore 全程 boot 日志（pstore2/3 两份独立代次）实测时序 = `11.63-11.79s kmodloader 加载 /etc/modules-boot.d/*（含 mtk_warp@11.78）→ 11.80s preinit → 18.27s procd early → 21.31s kmodloader 加载 /etc/modules.d/* → 22.32s mtk_wed → 22.36s hw_nat → 22.70s 完成`。preinit 期 bind-mount 遮罩有 ≈9.5s 余量，足够。
  c) **已知不可遮罩例外：mtk_warp**。它在 preinit 之前 10ms 由 `/etc/modules-boot.d/60-warp` 加载，且该路径无可写前置钩子（p26 rootfs 只读 squashfs）。⇒ S2 的语义**预写死为「mtk_wed 缺席 + warp 核心在位」**：若 S2 消融命中（消失），归因=写入者需要 mtk_wed 或 wed→warp 喂入路径（warp 单独残路径不在本臂排除内；A9 已证 WO 固件不是记录生产者，但 warp 主机侧 CCIF/rxcnt DMA 路径仍活）。warp 的 boot 期不加载需改 p26 镜像，列为后续 B4b，不在今晚。

## 5. 样本量/功效

- 窗：夹逼 arm0 **900 s ×4**（arm1 前/后、arm2 前/后——arm3 的后夹逼若时间不足可省，见停止规则 5）；消融臂 **1200 s ×3**。
- 预期事件数：写入者在线时历史记录率 1.0–127.6 条/min（10 §2 慢变漂移域）⇒ 1200 s 窗期望 24–>1000 条（下限按最静基线 S0-B1 4/900s≈0.27/min 也有 ≈5 条/1200s）。
- 最小可检效应：消融臂 0/1200s 的 95% 上界（rule of three）≈ **3 条/20min = 9 条/h**；对在线写入者（≥60 条/h）消失判别功效 >95%。
- 跨 boot 不可比声明（10 §2）：**每臂都是独立 boot，本实验只做存在/消失二分与 N/LOD 记录，禁止跨臂速率比**。夹逼 arm0 的作用=确认写入者当晚在线与量级，不是速率对照。

## 6. 混杂与控制

- **跨 boot 慢变状态**：A/B/A 夹逼（每消融臂前后各一个 arm0）；判据只用存在/消失。
- **流量构成**：arm1 必然失去 WiFi 客户端流量（PC 在 eth1 有线侧不受影响）。既有证据流量形态非决定因子（C-159，厂商内核态下取得）；预注册限定：若 arm1=V，不区分「S1 依赖」与「WiFi 流量构成依赖」，结论按集合口径表述。每窗记录 /proc/net/dev（eth0/eth1/br-lan/ra0/rai0/ccmni2）作协变量。
- **上行会话基线**（上行网按 MAC 记忆会话，「上行通」≠「认证守护活」）：每臂记录 authd 进程态、/tmp/authd_state、上游网关 ping、外网 ping。上行状态**变化**只记协变量不判 INVALID（写入者与流量无关，C-159）；上行承载口在 eth0，模块遮罩不改 MAC/不掉线。
- **04:00 定时重启**（reboot_sched 出厂默认）：会话避开 03:30–04:10；跨过则 03:30 后停工，之后按新代次分层。
- **模块缺席拖垮依赖服务**：每臂开窗前做服务存活清单（runbook 阶段2 步骤4；判据按 AGENTS 三定律：全集合扫描+排除自身，不用 pidof 取首）：dropbear/dnsmasq/v3httpd/watchdog/nerepair/wan_agg/hostapd（arm1 预期缺席）/蜂窝（ccmni 承载口有 IP）。清单失败不自动 INVALID——只有当失败**使 scanary 没跑完整窗**才 INVALID。
- **nerepair 在役**：属 v4.1 现役状态，全程不动（scanary 是自扫描探测，不经崩溃路径，S0 基线即在 nerepair 在役下取得 N=4）。
- **一轮一变量**：观测窗内不加任何新仪器；除遮罩文件外不改任何配置。
- **内核硬约束**：panic_on_taint/panic_on_oops 在位 ⇒ 任何 Oops=非计划重启=该臂 INVALID（10 §12）。
- **boot 形态改变本身**：遮罩=模块不加载，boot 时序/内存布局必然略变；这是消融实验的固有属性，不构成混杂项，但 arm0 夹逼必须**同一 enabler 代码路径**（中性遮罩文件）跑，保证「有/无遮罩条目」是唯一差异。

## 7. 停止规则

1. 全部 6–7 窗完成即停；得出 §4 组合表内结论即停，不追加窗口。
2. **boot 失败**（遮罩后 300 s 内 SSH 不回且串口见 panic 循环）：串口 toor 登录 → 写中性遮罩 → reboot → 该臂 INVALID；**同一臂当晚最多重试一次**且仅当根因是操作性（如遮罩文件传输损坏）而非模块相关。
3. 窗内非计划重启：该窗 INVALID；查 pstore；连续第 2 次 ⇒ 整场停工，恢复中性遮罩并报告。
4. 时间预算：阶段0+1 ≤60 min，阶段2 每臂 ≈30 min；**03:30 硬停线**或总时长 >5.5 h 先到者生效；到线时按已完成臂判读（组合表允许缺臂：缺臂按 E 处理不进结论）。
5. arm3 若时间不足：可省其后夹逼 arm0''''（arm2 后的 arm0''' 兼任其后验基线），arm3 判据改用「前夹逼 arm0''' ≥1 + arm3 =0」并在 §10 注明。
6. 安全红线：不写 p38/p39；不碰 bootctrl；一切设备写经 deploy.py put/push 或串口救援通道；每臂 misc[2061]（TRY_A）只读记录，>2 即中止后续臂（交恢复流程处置）。
7. 机制复核失败（runbook 阶段0 任一断言不过，含 rc.extend 修复引入新启动结构的情况）：**整场推迟**，不现场改机制。

## 附录 A · gw/mod_mask.sh v1.0 全文（钉死；今晚落地时逐字节采用）

```sh
#!/bin/sh
# mod_mask.sh v1.0 -- B4 module-load mask (SIGSEGV ablation enabler).
# Runs from babysit v3.1 at /etc/preinit time, BEFORE procd's rcS scan loads
# /etc/modules.d via kmodloader (~21s). Plain busybox sh only (pre-init env,
# no OpenWrt functions sourced). Reads /data/gw/ablation.mask: one module
# name per line ('#' comments and blank lines ignored). For every
# /etc/modules.d/* file whose line's first token matches a masked name,
# bind-mounts an empty file over it so kmodloader skips the entry.
# Empty/absent mask file => no-op (normal boot, zero behavior change).
# NOTE: /etc/modules-boot.d/* loads BEFORE preinit (mtk_warp) -- entries
# there are NOT maskable by this hook; do not claim otherwise.
MASK=/data/gw/ablation.mask
EMPTY=/data/gw/.mask_empty
MDIR=/etc/modules.d
LOGF=/data/gw/logs/ablation.log
mm_log() {
    echo "mod_mask: $*" > /dev/console 2>&1
    [ -d /data/gw/logs ] && echo "$(date '+%Y-%m-%d %H:%M:%S') up=$(cut -d. -f1 /proc/uptime 2>/dev/null) $*" >> "$LOGF" 2>/dev/null
}
[ -f "$MASK" ] || exit 0
[ -d "$MDIR" ] || { mm_log "FATAL no $MDIR"; exit 1; }
[ -f "$EMPTY" ] || : > "$EMPTY"
n=0
for name in $(grep -v '^#' "$MASK" | grep -v '^[[:space:]]*$' | cut -d'#' -f1); do
    hit=0
    for f in "$MDIR"/*; do
        [ -f "$f" ] || continue
        while IFS= read -r line; do
            case "$line" in \#*) continue ;; esac
            tok=${line%%[[:space:]]*}
            [ "$tok" = "$name" ] || continue
            if grep -q " $f " /proc/mounts 2>/dev/null || grep -q "	$f " /proc/mounts 2>/dev/null; then
                mm_log "already masked: $f"; hit=1; continue
            fi
            if mount -o bind "$EMPTY" "$f" 2>/dev/null; then
                mm_log "masked $name -> $f"; hit=1; n=$((n+1))
            else
                mm_log "ERROR bind failed: $f"
            fi
            break
        done < "$f"
    done
    [ "$hit" = 0 ] && mm_log "WARN no modules.d entry for: $name"
done
mm_log "done masked_entries=$n boot=$(cut -d. -f1 /proc/uptime 2>/dev/null)"
exit 0
```
