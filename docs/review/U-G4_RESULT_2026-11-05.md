## 1. 与 U-G3 判决的衔接

U-G3 已证:写者=总线级实时地址跟随(非缓存)。本轮把"地址可能藏在哪"穷尽到最后三类:
**GC 核 TCM**(MED 内三枚微码引擎,无软件读面)、**EMI/DRAMC 硬件观测器**(scp_bus_tracker 证明该基础设施在役)、**EL3 监视代理**(ATF,tee 分区在本地)。
内容源注意:FDMA_HNAT_INFO 证明 **FE 侧流信息确实流入 MED**(med 内容可见 eth 流量的机制通道存在)。

## 2. 下轮入口(按信息价值)

1. **MED 消融**(AT+CFUN=0 或 md force-stop):λ 归零=MED 复合体定罪;λ 存活=MED 出局→EMI-hw/EL3。需先解 atci 协议(ated/atcid 本地逆向)或用 poweroff 工具模式。
2. **tee/ATF(EL3)静态分析**:tee_b(86KB gz)在本地,签名封装需剥离;ATF 若内嵌 LK,解 lk_b。
3. **GC 核 TCM**:无直接读面;可经 medmcu SRAM 中的 GC mailbox 结构侧写(128KB 快照已在手,离线映射)。
4. sspm_b(424KB gz,熵 8.0)解包:tinysys 压缩头未解。
