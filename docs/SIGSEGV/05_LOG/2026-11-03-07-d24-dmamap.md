# 07 · D24 预注册 · DMA mapping 钩：抓「用户匿名页被 DMA 映射」（2026-11-03 D1）

> **预注册文档：实验开窗之前写定并 commit。实验后只追加 §9–11，不改 §1–8。**
> 编号 07 顺延（01..06 已占用）。中性命名：不含目标网络名与个人凭证。

## 1. 问题

32B 记录族 `{u32 X, 0, u32 len, __be32 ip, 0...}` 的写入者身份。D23（C-206）已
**物理性排除** CPU uaccess 漏斗 `__arch_copy_to_user`（热窗 1230 s + 确认窗 660 s，
2895 万次漏斗调用、家族内容命中 0）。N2d §§5-D 给出唯一剩余类别：**DMA/总线主写**
——CPU 只把目标 PA 编程进描述符，硬件直写 DRAM，天然绕过所有 uaccess 普查。

若写入者的目标页是（或曾经是）**用户匿名页**，则主机侧必须先把该页 `dma_map`
（取得 DMA 地址写进描述符）。反过来说：**若在有效窗内没有任何 `PageAnon(page)`
的 dma_map，则"主机把用户匿名页 DMA 映射后由描述符写回"这条通道可排除**
（残余为 raw-PA 编程 / follow_pfn 重译——D2 线并行）。

## 2. 假设（先写死）

- **H_dmamap**：写入者的目标页曾经/正在被 DMA 映射（主机侧 `dma_map_*` 用户页），
  硬件按描述符写回该页。判据 = 有效窗内捕获到 `PageAnon(page)` 的 dma_map。
- **H_other**：不存在用户匿名页的 dma_map；DMA 通道若存在，目标 PA 来自
  raw-PA 编程（不经 `struct page`/dma_map）或页表重译（follow_pfn 类）。

## 3. 仪器

- **模块**：`dmahook.ko`（源码 `tools/oneoff/sigsegv/bmods/dmahook.c`）。
- **站点（两个，同一 4K 页 0x…819a000）**：
  1. `dma_map_page_attrs` @ `0xffffffc00819aef0`，期望首 4 字节 `3f 23 03 d5`
     （`paciasp`）；覆盖 `dma_map_page` / `dma_map_single` 全部调用式路径
     （5.15 中 `dma_map_page_attrs` 是 out-of-line 导出函数，`dma_map_single_attrs`
     的 per-TU 克隆全部调用它）。
  2. `dma_map_sg_attrs` @ `0xffffffc00819a6f4`，期望首 4 字节 `3f 23 03 d5`
     （`paciasp`）；覆盖 `dma_map_sg` 族（sg 逐项 `sg_page()` 扫描）。**这是
     网络/存储 scatter-gather 数据面的入口**；不钩它会把最主要的 DMA 路径漏掉。
- **补丁原语**：与 D23 相同（rodata_full 下 `__va(pa)` 亦 RO）：TTBR1 页表遍历取
  site 页 PA → `pfn_to_page` → `vmap(1 页, PAGE_KERNEL)` 自建可写别名 → 别名写
  4 字节 `b <trampoline>` → 对 image VA 每 CPU `dc civac + ic ivau` → `vunmap`
  （还原后）。安装/还原在 `stop_machine` 内；逐站点读回断言 3 次重试。
- **trampoline（每站点一条）**：先保存 x0–x5/x29/x30（**在改 SP 之前**记录原始
  x30=lr；`paciasp` 放到恢复 SP 之后、跳回 site+4 之前执行，保证函数内 `autiasp`
  的签名语义与原始路径完全一致），调用 C 过滤函数，然后执行被替换指令并跳回 site+4。
  `b` 距离 init 时实测计算，越界即失败、不 patch。
- **过滤器（按任务书）**：`(unsigned long)page->mapping & 1`（PAGE_MAPPING_ANON）。
  - 页指针先做 vmemmap 范围校验（`VMEMMAP_START=0xfffffffe00000000`,
    `VMEMMAP_END=0xffffffff00000000`, 64B 对齐），越界只计数不读；
  - `compound_head` 做**安全**版：bit0 置位的 head 指针必须落在 vmemmap 且
    64B 对齐才解引用（防 page_pool `pp_magic` 等非 tail 页误判→野指针）；
  - `mapping`/`compound_head`/`_refcount` 偏移用 `BUILD_BUG_ON` 与
    `offsetof` 钉死（expect 24 / 8 / 52，sizeof(struct page)=64）。
- **记录（per-cpu 无锁环，128 条/CPU）**：`ts(cntvct) lr page head pfn phys
  offset size dir attrs mapping refcount mapcount trace[4] pid comm flags`。
  另每 CPU 记录**前 8 条非匿名调用样本**（`flags=SAMPLE`），用于证明钩子在真实
  驱动路径上被行使（lr 符号化应落在 mmc/wifi/mm 等真实调用者）。
- **正对照（仪器有效性）**：`echo 1 > /proc/dmahook` 触发一次内部 selftest：
  从真实调用中捕获的 `struct device *`（last_dev）取一个有效 dev；
  `alloc_page(GFP_KERNEL)` 取自有页，临时置 `compound_head=0`、`mapping=(void*)1`
  （PageAnon 形状），分别调用 `dma_map_page_attrs(dev, page, 0, 32, DMA_TO_DEVICE, 0)`
  与 `dma_map_sg_attrs(dev, sg, 1, DMA_TO_DEVICE, 0)`，随后 unmap、恢复字段、释放页。
  **预期：恰好 1 条 PAGE 命中 + 1 条 SG 命中，lr 落在 dmahook 模块符号**。
- **计数器**：每 CPU `calls_page / calls_sg / sg_entries / pbad / anon / recd /
  dropped / samples`；总调用数 = 各 CPU 之和（非原子，允许轻微抖动）。
- **dryrun=1**：只定位 + 字校验 + PA/别名读回 + 分支距离，**不写一字节**。

## 4. 窗与有效性门禁（任一不满足 ⇒ 该窗 INVALID）

1. `insmod dryrun=1`：两站点字校验通过（`paciasp`）、PA/别名读回一致、
   分支距离 ∈ (−128MB, +128MB)、`BUILD_BUG_ON` 布局自检通过（init 打印 offset）。
2. live：`INSTALLED`（两站点）、`/proc/dmahook` 头行 `PATCHED`、站点读回 = 我们写入的 `b`。
3. **窗 ≥1800 s，背景态**：无 WiFi 客户端（PC 不切设备 AP；若用户手机恰好重连，
   记录实际 `station dump` 客户端数作为协变量）。窗内 `boot_id` 不变、无 oops/panic/重启。
4. **正对照在窗内执行**：selftest 产生 1 条 PAGE + 1 条 SG 匿名命中（lr=模块符号），
   证明过滤+记录+匿名判据链真的在跑。
5. **钩子被真实路径行使**：`calls_page + calls_sg > 0` 且 ≥1 条 SAMPLE 记录的 lr
   可符号化到真实驱动/内核函数（非零页/非零 PA 合理）。
6. 窗内 canary（vsurv5，`/data/repro/h5_*` dump 计数增量）≥1 或 canary 进程存活
   且 CPU 增长（证明"写入者背景活跃"这一协变量可测）。
7. 收窗：`rmmod` 后两站点读回 = 原始 `3f 23 03 d5`（还原断言）、0 个我方模块、
   `/proc/dmahook` 消失、`TRY_A` 低字节=0。

## 5. 判据（预写死，不改）

- **主判据（H_dmamap）**：有效窗内 **PageAnon 命中数 > 0**（不计 selftest 的
  PAGE/SG 正对照；按 lr+pid+comm 排除）⇒ H_dmamap 成立；命中样本的 lr
  （`/proc/kallsyms` 符号化）即映射者调用链。
- **排除判据（H_other 上位）**：匿名命中 = 0 **且** §4 门禁 1–6 全满足 ⇒
  对**背景态**、对 `dma_map_page_attrs`/`dma_map_sg_attrs` 两个 wrapper 覆盖的
  调用式 DMA 映射，**用户匿名页通道排除（E2）**；残余 = raw-PA 编程 / follow_pfn
  重译 / 直接调用 `dma_direct_map_page` 或 `ops->map_page/map_sg` 的驱动（罕见），
  以及"映射发生在窗之前且未重映射"（陈旧映射——若描述符持有旧 DMA 地址，
  窗内本就不会有新 map；该情形由 canary 命中与 D3 patrace 的活槽页 PA 对照证伪/证实）。
- 若命中 > 0 但全部可归因于 selftest ⇒ 视同 0（selftest 单独标记）。
- 若仪器缺陷导致崩溃：崩溃预算 ≤2；同一缺陷重复出现即停（不改判据救场）。
