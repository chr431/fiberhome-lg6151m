## 一、统一原则

1. **一词一义**：同一概念在全部页面、标签、按钮、提示、错误信息中只用一个词。
2. **一义一词**：同一词不得同时承担两个概念（如"上行""模式""5G"当前均违反）。
3. **用户视角优先**：面向用户的词描述"用户能观察到什么"，不描述"系统内部怎么实现"
   （`hostapd`、`quecadp`、`iptables`、`wan_agg`、`状态机` 等一律不进界面）。
4. **平台无关**：不用只在某代硬件/某个测试环境成立的表述（`slot-A`、`RP0103`、
   `MT6990`、实测频点示例值）。
5. **首现全称、后续简称**：如"蜂窝（5G/4G）"首次出现，之后统一"蜂窝"。
