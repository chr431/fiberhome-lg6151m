# 2026-10-31-01 h4 普查与解析器修正（A 轨道）

## 0. 预登记
- 假设：vsurv4 的 H4v1 dump 包含 fault-time va_list 记录；用 va_scan 的 shape 定义扫描 8 页栈。
- 判据：shape A0B2/B0A2 出现在 x2 或 x2-0x240；正控=手工构造；负控=h4_test。
- 预期：若 canary 捕获记录，多数 h4 应有 record。

## 1. 解析器修正（关键）
- 旧解析（C-127..C-129）用**字面字节** `b2 a0`/`a2 b0` 搜索 -> 0 命中 -> 错误结论“h4 无 record”。
- 正确做法：用 va_scan.py 的 **shape** 定义（w0 small/big、w1=0、w2 big/small、w3=0），按 8 字节对齐扫描。
- 结果（17 份）：**13/17** 有 record；位置 x2、x2-0x130、x2-0x240；`top-x2=0x390` 恒定。
- 结论：C-127/C-128/C-129 **retract**；新增 C-137。

## 2. 全量普查（112 份）
- 设备 `/data/repro/h4_*` 共 145+（普查时拉取 112 份；111 个 h4_* + h4_test）。
- 采集：`h4_fetch.py` 单 SSH 连接顺序 cat（避免 dropbear 高频 spawn 卡死）；94/94 成功。

## 3. 解释
- h4 是 **canary**（vsurv4 捕获 SIGSEGV 后写 dump 并 siglongjmp），所以 78.6% 是 **canary 放大**，不是自然 NE 份额。
- 自然 NE 份额仍用自然 core（0/3，95% 上界 63%）；canary 88/112 只证明 **canary 是有效探测器**（C-139）。
- `top-x2=0x390` 恒定 + 记录三副本（x2 / x2-0x240 / x2-0x130）支持“record 覆盖 live va_list 的多个副本”模型（C-052/C-063/C-140）。
- **transport 仍未判决**：canary 记录落在自身栈，VA-targeted 与“stale PA=当前栈页（回收页）”都可解释（C-140）；需要页级 probe。
