## 1. 关键实验时间线(证据全在 ug2_eviblob.txt,f55e83a6)

1. **store-监控穿透窗**(victim 31085,槽 0x7ff9b36910/…770):flip 实验中,uva=…770 布防(alias+uva 双形态 EL1 store)后
   **+75 落地零 fire**、整机存活 ⇒ 非 EL1 store。
2. **槽位切换误判纠正**:首次布防后旧槽冻结曾疑"写者感知观察点";flip+中性对照证明=写者自然换槽/受害者扰动,非全局感知。
3. **loadmix 窗**:load 观察(alias-EL1+uva-EL0 双形态 q0/q1)布防 3 秒内 λ 冻结;ring 仅 2 条=观察者 head 自身栈碰撞
   (观察者污染第三形态);无任何内核 pc 事件、无整机死 ⇒ 写者的"读"不经这两通道(K9 细化:门控键于受害者执行保真度,
   与观察点无关)。
4. **七环齐poll**(victim 13448,PA=0xb0a0ca10,TX_BM=0xa7700000/RROQ=0xa8f00000/TX0=0x9cf90000/TX1=0x9cf98000/RX_BM=0xa9d80000):
   全零,同期 171 落地。
5. **hw_nat 消融**:rmmod → LAN 断(eth1 弹跳恢复)→ λ 继续;模块回归。
6. **ringfind**(内容签名环发现):201 CAND/11 页(截断),victim 26612(PA=0xa7302d50)90s×11 页全零,同期 156 落地。
7. PA-scan 16"持有者"全解伪:五连簇=pascan 自栈(含 argv/env,跨页移动=每次扫描新栈页);f50 三连=三个 ringpoll 的 argv 目标值;
   0xa76e02d8=patrace 缓存;随机值对照 3 命中=壳计数器巧合底噪。

## 3. 事故与纪律(新增)

- #8–#11 四次复位全因**厂商 debug/MMIO 接口**(tracer 写×2 挂死、cr WDMA 读、盲 ioremap 读窗[读清型寄存器副作用])——
  本项目对该类接口的立场改为"默认有害,只在源码核对读副作用后使用";
- 观察者工件分类学(判读全 RAM 扫描必读):①扫描器自栈(目标值+argv/env 指纹,跨 run 移动)②并行工具 argv(每个工具
  一处目标值)③patrace 查询缓存④shell 堆数值巧合(随机值对照测底噪);
- ringfind 200-CAND 截断教训:探索型扫描器不得设静默上限(6% 覆盖当成了全量);
- hw_nat 消融的 LAN 断路径:rmmod PPE 模块后需 `ip link set eth1 down/up` 恢复交换路径;
- lgssh 管道 hex 流会被偶发污染:分块拉取必须逐块纯度校验+重拉。
