# 2026-10-31-04 pg2 栈页 PA 测量（B 轨道，部分）

## 0. 预登记
- 假设：若 transport 是 PA/DMA + 页复用，canary 栈页的 PA 应等于回收的 WED TX 页 PA；若 uaccess/VA，PA 无此约束。
- 判据：pg2 读出 canary 栈页 PA；与 WED TX 页 PA 对比（后者需 pgprobe）。
- 正控：pg2 在已知 anon 页上返回 anon=1 mapc=1；负控：非 present 页返回 zero page 哨兵。

## 1. 实测
- pg2.ko pids=8626,8627,8628 npages=16。
- 栈页 PA：
  - 8626: page0 0xaea1e000, page1 0xb06cf000（top&0xfff=0x190，x2=top-0x390 在 page1）
  - 8627: page0 0xaf95d000（x2 在 page0）
  - 8628: page0 0xae97c000（x2 在 page0）
- 非 present 页：pa=0xfe956000（zero page 哨兵，anon=0 mapc=0 lru=0）。
- 结论：canary 栈页是**普通 anon 页**，PA 随 pid 变化；pg2 无法直接看到“回收的 WED 页”。

## 2. 判决状态
- transport **仍倾向 PA/DMA**（C-140：88/112 固定 top-relative 偏移 + w2=len|ip；外部 uaccess 拿不到 va_list VA）。
