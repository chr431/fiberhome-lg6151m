## 3. 终局判决书(给 VERDICT §15 的正文)

**写者 = EMI/DRAMC 内部硅引擎(post-MPU 注入)**——不是任何软件:

| 层 | 出局证据 |
|---|---|
| EL0 用户态 | U-G1:非 STTR |
| EL1 内核(含 linear-map 别名) | C-228:alias+uva 双 VA store watch,171 落点零触发 |

| EL3/BL31 | U-G6:静态全读,无形状/无词汇/无触发(§0 第一行) |
| 全部协处理器+总线 master(GC×3/SSPM/MCUPM/SPM/DPM/MED/wocpu/PPE/EDMA/WED) | U-G5:16 域穷尽拒绝 λ 不塌(阳性对照 2400+ 违例);modem 管辖由内核专用 MD 违例机器佐证 |

⇒ 写者的 DRAM 写端口**不带任何 EMI MPU 域**;同类只有 CPU 端口(全软件出局)与 **MPU 之后的
内部通路** ⇒ 存储子系统内部注入。内容=本机硬件卸载流(唯一生产者 MED hnat_info 族,其数据经
EMI 内部观测面——与 ISU 同面——喂给注入引擎;MED 本体管辖出局)。C-239 的"总线级活址跟随"
观察成立,其机制归宿即该 post-MPU 层(窥探点注入),而非任何 master。

**嫌疑对(均 EL3 门禁、均有 DRAM 写能力,本轮均无法以名字排除)**:
1. EMI-ISU(自有 0x80B 记录族在 8MB 保留 buf;无 32B 族;con 寄存器 EL1 读写皆致死 #17/#18)
2. DRAMC DRM_DEBUG 族([DRAMC-ATF] 访问器存在;AO/NAO 可见调试寄存器读=0;DDRPHY+0x1520 致死)

**下一发点名弹(已具备,零地雷路径)**:内核已有导出的 SMC 控制路径(mtk_emiisu_control +
emiisu_ctrl_store sysfs;DRAMC-ATF 访问器 SMC 号待从 SIP 分发器提取)⇒ 做 **λ-vs-引擎关断
对照实验**:经 SMC 逐一关断 ISU/DRAMC-debug,λ 塌者为名。风险=参数错可能复位(授权内)。
